The Model

three-layer prediction pipeline

The prediction uses a three-layer architecture. Every weight and constant is documented below so you can audit or reproduce it.

LAYER 1 · STATISTICAL LEARNING
Multinomial Logistic Regression
Trained on real World Cup matches (2010, 2014, 2018) to predict Win / Draw / Loss for each team. The regression learns how much each feature contributes to winning — these learned coefficients become the Power Index weights used for 2026 predictions.

Features: Elo difference between teams, pedigree difference (WC titles × 8 + appearances × 0.6), and host flag. Algorithm: gradient-descent softmax regression (pure NumPy).
LAYER 2 · MATCH PROBABILITY
Poisson + Dixon-Coles
Converts the effective Elo gap into expected goals, then enumerates the joint scoreline distribution for exact Win / Draw / Loss probabilities.

λA = μ · exp(+γ · Δelo / 400)
λB = μ · exp(−γ · Δelo / 400)
μ = 1.35 · γ = 0.85.

A Dixon-Coles correction (ρ = −0.08) lifts the low-score cells so the draw rate matches reality (≈26%) — plain independent Poisson under-predicts the favourite-vs-minnow draws.
LAYER 3 · TOURNAMENT SIMULATION
Monte Carlo Simulation
Plays the full 48-team / 12-group 2026 bracket times using the Poisson model for every match. Group stage → best-32 advance → R32 → R16 → QF → SF → Final. Counting how often each team wins each stage yields title %, final %, semi %, and KO-advance %.
PARAMETERS TRACKED PER TEAM
Feature Engineering
Elo rating — overall strength from match history.
Squad value & key players — current squad quality (€M market value).
Recent form — points from last 10 competitive games (W=3, D=1, L=0); updates live as 2026 results come in (not just Elo).
Historical pedigree — WC titles × 8 + appearances × 0.6, capped at 12% so history can't outvote current quality.
Fitness / availability — % of first-choice XI fit going into June 2026 (injury news).
Squad trajectory / age — average starting-XI age: younger, rising squads rewarded, ageing squads penalised.
Host advantage — flat bonus for USA / Mexico / Canada.
Head-to-head record — small Elo nudge for specific rivalries.
Recency weighting — training matches decay with a 7-year half-life, so Euro 2024 / NLF 2025 results count ~4-5× more than 2010 matches.

🔴 Live 2026 Updates

online learning · real-time model adaptation

As 2026 World Cup matches happen, record each result. The model uses a TD-learning Elo update (the same mathematics as Q-learning / reinforcement learning) to adjust every team's strength rating, then retrains the logistic regression on historical + 2026 data and rebuilds this dashboard automatically. Each result makes the predictions more accurate.

How to add a result

# Record a match result then rebuild python3 wc2026_live.py add ARG FRA 3 3 final # Show all recorded results python3 wc2026_live.py list # Undo the last entry python3 wc2026_live.py undo # Stage options: group | r32 | r16 | qf | sf | final # Goals = 90-min score (AET/pens counts as draw)
Why this is reinforcement learning:
The Elo update rule — ΔElo = K·G·(S−E) — is mathematically identical to TD(0) learning: the "reward signal" (actual S minus expected E) drives a gradient step on the team's strength estimate. K=20 (group), 25 (knockouts), 30 (final); G is a goal-difference multiplier (×1 / ×1.5 / ×(11+GD)/8) so a 7-1 win moves ratings far more than a 1-0. After each update, the LR model retrains so W/D/L probabilities recalibrate for the rest of the tournament.
